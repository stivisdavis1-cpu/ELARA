# Application Mobile

- **Rôle :** Frontend Mobile (React Native / PWA)
- **Couches :** Layer 6 (Action) / Layer 1 (Ingestion Mobile)
- **Détail :** Approche "Mobile-first" tolérante aux interruptions. Permet l'ingestion de documents via la caméra et le fonctionnement partiellement offline avec synchronisation. Consomme l'API `/v1` de NestJS.
