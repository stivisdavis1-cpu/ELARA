Elara — API d'intégration (entrantes / sortantes)

Version 1.0.0 · OpenAPI 3.0.3

API d'intégration multi-tenant d'Elara, permettant de connecter la Business Memory d'une entreprise aux systèmes déjà utilisés (comptabilité, banques, Mobile Money, ERP, CRM, WhatsApp Business, email) sans exiger leur remplacement.

Principes structurants - Chaque requête est scopée à un tenant unique (`tenant_id` porté par le jeton d'accès ou la clé API). - Toute action *sortante* à impact financier ou client requiert une validation humaine explicite dans Elara avant exécution (voir `statut: en_attente_validation`). - Chaque appel entrant ou sortant est journalisé dans l'audit trail du tenant. - Toutes les routes sont versionnées (`/v1`) afin de garantir la compatibilité ascendante des connecteurs existants lors de futures évolutions. - Les endpoints sont soumis à une limitation de débit par tenant et par intégration (voir en-têtes `X-RateLimit-*`).

Serveurs

  • https://api.elara.app/v1 — Production
  • https://sandbox-api.elara.app/v1 — Bac à sable (sandbox) — données de test, sans impact réel

Authentification

  • OAuth2 — OAuth2 (client credentials), token via POST /oauth/token
  • ApiKeyAuth — Clé API dans l'en-tête X-Api-Key

API sortantes

Actions déclenchées par Elara sur les systèmes existants de l'entreprise, avec validation humaine pour les actions sensibles.

POST/sortantes/factures

Créer ou mettre à jour une facture dans le logiciel de comptabilité

Action sensible : soumise à validation humaine explicite dans Elara avant exécution.
La réponse initiale renvoie `en_attente_validation` ; le statut final est communiqué
par webhook (`facture.validee` / `facture.rejetee`) ou par consultation du statut.

Corps de la requête
ChampTypeDescription
commande_idstring (uuid)
client_idstring (uuid) *(requis)*
lignesarray *(requis)*
devisestring
date_echeancestring (date)
Réponses
CodeDescriptionChamps principaux
202Demande acceptée, en attente de validation humaineid, type, statut, cree_le, valide_par, valide_le
401Authentification manquante ou invalidecode, message, details
422Données invalidescode, message, details
